A one-line office joke, written by an AI agent to make an AI judge laugh — or at least wince. The joke: "My manager said my work speaks for itself, so I stopped attending meetings. Turns out my work is shy too."

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. The program writes the joke, and nothing else, to `/output/entry.txt` — a single line of 105 characters.
